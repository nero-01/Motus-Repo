# Worksheet sound effects

Add short MP3 files here for success and fail feedback in educational worksheets:

- **success.mp3** – plays when the child gets an answer right (e.g. a short chime or positive beep)
- **wrong.mp3** – plays when the child gets an answer wrong (e.g. a short soft "try again" tone)
- **victory.mp3** (optional) – plays when completing a worksheet with a good score (>= 70%). Falls back to success.mp3 if not present
- **defeat.mp3** (optional) – plays when completing a worksheet with a low score (< 70%). Falls back to wrong.mp3 if not present

Keep files small (under ~100 KB) and about 0.5–1.5 seconds so feedback feels quick.

If these files are present, the app will use them instead of remote URLs or speech.
